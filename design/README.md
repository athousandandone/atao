# Design

This directory contains the enduring design direction for the **A Thousand And One** website.

It exists to capture the principles behind the visual language rather than implementation details. The objective is to preserve _why_ design decisions were made, allowing the implementation to evolve without losing its editorial identity.

Design artefacts, experiments and mock-ups are transient. The documents in this directory record only those decisions that have become part of the intended direction.

## Contents

### `mi-publication-direction.md`

The editorial and visual direction for the MI publication, including its reading experience, typography, layout philosophy and relationship to the wider A Thousand And One identity.

## Principles

The design should:

- favour reading over navigation
- favour typography over decoration
- favour longevity over trends
- embrace semantic HTML and progressive enhancement
- remain calm, understated and content-first
- avoid introducing complexity that does not create value for the reader

As with the rest of the endeavour, every design decision should earn its place.
